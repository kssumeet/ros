# D — Image alt text and file-naming plan

## Rules for alt text
1. **Describe what is in the photo**, as you would to someone who can't see it: the object, the room type and anything distinctive. Aim for 8–16 words.
2. **Add the room type or use** where it helps: "dedicated home theatre", "living room", "boardroom", "recording studio".
3. **Add "Ranchi" or a client/area only when it is true and natural.** Use it on real project photos ("…in a Harmu, Ranchi apartment"), never on a product shot or a stock image.
4. **One idea per image. No keyword lists**, and never repeat the same alt text on two images.
5. **Brand names only when the brand is visible** and ROS is allowed to sell it ([confirm partners]).
6. **Leave out "image of" and "photo of".** Screen readers already announce it's an image.
7. **Decorative images** (textures, dividers, background patterns) get `alt=""`.
8. **Client and project names** only `[with permission]`.
9. **Stock or manufacturer photos** must not be described as ROS work ("ROS installation") unless they are. Replace them with ROS photography where possible.

## File-naming convention
`[subject]-[room-or-use]-[place-if-real]-[nn].webp`: lowercase, hyphens only, no dates or camera numbers.

| Good | Bad |
|---|---|
| `dolby-atmos-home-theatre-ranchi-01.webp` | `Untitled-1.jpg` |
| `acoustic-panels-studio-control-room-02.webp` | `fdfdgfdgdfgb.jpg` |
| `motorised-recliners-riser-home-cinema-01.webp` | `WhatsApp-Image-2025-01-05-at-5.0.jpg` |
| `ros-demo-room-ranchi-screen-01.webp` | `23.jpg` |

Use `ranchi` in the filename only when the photo was taken in Ranchi. **Size:** maximum 2000 px on the long edge, WebP at ~80 quality, aiming for under 250 KB (hero images under 300 KB).
